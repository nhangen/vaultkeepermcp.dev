Documentation

Build on VaultKeeper MCP.

Install the server, connect a harness, and read the write contract. Everything runs on the host that holds your vault.

Quick start

01

Get the code

Clone the repository, install the locked dependencies, and run the test suite. You need Node.js 20 or newer.

02

Point it at your vault

The stdio server starts in the read profile. Set MCP_STDIO_PROFILE=write to expose the write tools.

03

Or install the plugin Recommended

Claude Code and Codex users can skip both steps. The plugin installs or reuses a verified runtime for you.

Every write has one owner.

MCP failure never falls back to a vault mount or a local keeper. A failed write says so in its result and names the recovery step, so you always know what reached the vault.
