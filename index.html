How it works

The Vault Keeper

The Keeper holds the keys.

Agents submit structured write requests with a target folder and an idempotency key. The Keeper handles every vault edit: it writes the note, reconciles the folder’s INDEX, and reports every path it touched.

Plugin stop hooks

Sessions save themselves at Stop.

The Claude Code plugin uses the Stop hook to check for work worth saving whenever Claude finishes a response. The hook marks each new segment of the transcript so it’s picked up only once, then hands it to a background process that summarizes the work and sends the note to the Keeper. The plugin waits for you to retry if processing fails.

Access

Enforced read limits and access controls.

Vault access starts in read-only mode. Remote requests need a token and can only perform actions that the token permits. Tokens are sent separately from the URL.
